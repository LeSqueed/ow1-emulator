# Overwatch: Recall

**A custom competitive Overwatch experience by LeSqueed**

This repository contains OverPy source code for "Overwatch: Recall", a custom Workshop gamemode focused on creating the best competitive Overwatch experience.

## Philosophy

Overwatch: Recall is designed to provide:
- **Unique balancing** tailored for enhanced competitive play
- **New hero mechanics** and system integrations where they improve gameplay
- **Quality-of-life improvements** that address OW1/OW2 pain points
- **Focus on what makes Overwatch fun** while removing elements that hinder competitive integrity
